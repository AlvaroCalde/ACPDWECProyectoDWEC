¡Bienvenido/a a mi repositorio de **Desarrollo Web en Entorno Cliente**! 👋 

Este espacio está dedicado a almacenar todos los proyectos, ejercicios, prácticas y apuntes relacionados con la programación del lado del cliente en aplicaciones web.

## 📝 Sobre este repositorio

El objetivo principal de este repositorio es documentar mi aprendizaje y progreso en la creación de interfaces web dinámicas e interactivas. Aquí encontrarás desde conceptos básicos de manipulación del DOM hasta aplicaciones más complejas utilizando frameworks modernos, consumo de APIs y gestión del estado.
